# Achint & Harshita · Wedding Invitation

A single-page wedding invitation website for 23 & 24 November 2026 at Spara Boutique Resort by Chhabara Farms.

Everything lives in `index.html`: photos, fonts, animations and the calendar invite are all built in, so there are no other files to upload.

## Publish with GitHub Pages
1. Open the repository's Settings, then Pages.
2. Under Build and deployment, choose "Deploy from a branch", select `main` and `/ (root)`, and save.
3. After a minute or two the site is live at https://achintvii.github.io/weddingV1/

## Update the invite
Replace `index.html` with the new version (Add file → Upload files) and commit. The live site refreshes within a few minutes.
